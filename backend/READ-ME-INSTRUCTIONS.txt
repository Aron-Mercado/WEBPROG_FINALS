Setup (see README.md in project root):

1. copy backend\.env.example to backend\.env — set DB_PASS
2. copy frontend\finalsFrontEnd\.env.example to frontend\finalsFrontEnd\.env — set VITE_API_BASE
3. Import backend\sample_data.sql or use existing food_delivery DB
4. XAMPP: place project under htdocs\php\Finals (or your path)

Never commit .env files or database export dumps to GitHub.
